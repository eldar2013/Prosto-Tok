# Prosto Tok

Самостоятельное Android-приложение с вертикальным просмотром видео.

## Текущий этап
- Android-приложение на Java
- Воспроизведение выбранного пользователем видео из памяти телефона
- Основа для дальнейшей разработки ленты

Это не модифицированный клиент TikTok и не подключение к закрытой ленте For You. Для онлайн-контента потребуются разрешённые источники или официальные интеграции.

## Сборка
Откройте вкладку Actions в GitHub и запустите workflow Build Android APK. APK появится в Artifacts после успешной сборки.
